# Набор Приёмочных Тестов (Acceptance Tests)

> **СТАТУС ДОКУМЕНТА**: `SPECIFICATION` / `TESTS`

---

## Разделение Продуктовых и Синтетических Тестовых Фикстур

Тесты платформы четко разделяют два типа фикстур: [`POLICY`]

1. **Production Targets (Реальные объекты СУБД)**: Используются в интеграционных тестах. Копируются из `map_targets` посимвольно (например: `Moma`, `Ula`, `Bhima`, `Bahía de Campeche`, `Island BORNEO`, `Island Bora Bora`). [`POLICY`]
2. **Synthetic Unit Mocks (Синтетические моки)**: Используются исключительно в изолированных unit-тестах структурного контракта. Явно помечаются префиксом `SYNTHETIC-UNIT-` (например: `SYNTHETIC-UNIT-RIVER-01`). Смешение синтетических моков с проверками продуктового реестра СУБД категорически запрещено. [`POLICY`]

## Реестр Приёмочных Сценариев

### `TEST-ACC-01`: Обработка реального незаполненного объекта `river`
- **Тип**: Production Target
- **Вход**: `{ "map_type": "river", "target_id": "Moma", "title_ru": "Мома", "title_en": "Moma" }`
- **Ожидаемый результат**:
  - `exact SELECT` подтверждает существование в `map_targets` и отсутствие истории в `map_stories`.
  - Успешный прогон всех 10 стадий конвейера.
  - JSON-массив из ровно 3 ключей (`"map_type"`, `"target_id"`, `"content"`).
  - `target_id` посимвольно сохранен как `"Moma"`.

### `TEST-ACC-02`: Срабатывание стоп-условия при существующей истории
- **Связанный STOP-ID**: `STOP-META-03`
- **Вход**: Объект, для которого в `map_stories` уже есть запись `language = 'ru'`.
- **Ожидаемый результат**: Немедленный останов (STOP), объект отбраковывается.

### `TEST-ACC-05`: Неподтвержденные факты на этапе Research
- **Связанный STOP-ID**: `STOP-RESEARCH-01`
- **Вход**: Объект с спорными сведениями.
- **Ожидаемый результат**: Отбраковка объекта (STOP), объект не попадает в итоговый JSON.

### `TEST-ACC-06`: Неподтвержденный факт автора в Fact Check
- **Связанный STOP-ID**: `STOP-FACT-01`
- **Вход**: Черновик автора содержит факт вне `confirmed_facts[]`.
- **Ожидаемый результат**: Отбраковка объекта (STOP).

### `TEST-ACC-07`: Нарушение тональности или закрытый CTA
- **Связанный STOP-ID**: `STOP-KIDS-01`
- **Вход**: Черновик с закрытым вопросом («Хотел бы поехать?»).
- **Ожидаемый результат**: Отбраковка объекта (STOP).

### `TEST-ACC-10`: Сквозная проверка 11 критериев DoD
- **Связанный STOP-ID**: `STOP-DOD-01`
- **Ожидаемый результат**: PASS только при совпадении всех 11 критериев Канонического DoD.
